common-passwords.txt is built from ignis-10M.txt of Pwdb-Public,
https://github.com/ignis-sec/Pwdb-Public, git blob 16e9bbb9d240c9d4271621d5dcd88e63b52cc696.
SecLists ships the same file as Passwords/Common-Credentials/Pwdb_top-10000000.txt,
https://github.com/danielmiessler/SecLists.

It keeps the entries of 15 to 128 code points, normalised to NFC, lower-cased, without duplicates
and sorted ordinally. Lines that were not valid UTF-8 and lines that contain an email address
are left out.
